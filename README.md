Sizzle & Serve — Rush Hour Kitchen: a complete original cooking game. Run a frantic little kitchen through a 2½-minute shift: take orders off the board, grab ingredients from the fridge, chop them on the board, cook patties on the stove (don't let them burn), stack plates on the assembly counter and serve them at the window before the customers' patience runs out. Four recipes, growing pressure as rush hour hits, combos for back-to-back serves, and a best-score chase. Keyboard and mouse, no build step, no network — just open game/index.html in a desktop browser.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — or open game/index.html directly in a desktop browser.
